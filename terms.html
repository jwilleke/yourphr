  • You also accept that provider’s or CMS’s terms, policies, and API rules.
  • You must only import records you are authorized to access.
  • The software is intended for read access to your own records, not for changing data held by providers or CMS.

A public sign-in relay may briefly hold an OAuth authorization code (not health data, not access tokens). See the Privacy Policy.
